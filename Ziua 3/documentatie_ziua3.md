2. Box Model: Margin vs Padding
Padding: Spațiul din interiorul cutiei (între text și bordură).

Margin: Spațiul de la exteriorul cutiei (distanța față de alte elemente).

3. Sintaxa Selectorului de Clasă
Se folosește un punct (.) urmat de numele clasei definit în HTML.

HTML: <div class="card">

CSS: .card { color: red; }
